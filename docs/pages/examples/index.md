# Examples

The files in `examples/types/` are runnable and self-checking: each calls `fail(...)` on a wrong result. Run all of them with `examples	ypesun.ps1`.

| Example | Topic |
|---------|-------|
| [Primitives](primitives.md) | int, float, bool and string behaviour and conversions. |
| [Collections](collections.md) | Arrays, sized arrays, maps, sets and iteration. |
| [Structs and enums](structs_enums.md) | Struct copy semantics, enums with payloads, match, Option, Result and `?`. |
| [Generics and traits](generics_traits.md) | Generic functions, traits and operator overloading. |
| [Functions](functions.md) | Lambdas, higher-order functions and recursion. |
| [Operators](operators.md) | Every operator with its expected result. |
| [Math library](math.md) | Integer, rounding and floating point math. |
| [Benchmarks](bench.md) | Timing loops, recursion, lists and maps. |
